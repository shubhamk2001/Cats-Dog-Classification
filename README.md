# Cats and Dogs Image Classification

A deep-learning notebook project for classifying images as cats or dogs.

## Contents

| File | Description |
| --- | --- |
| `Image Classification (Cats&Dogs).ipynb` | Notebook containing the image-classification workflow. |

## Workflow

1. Load and prepare labelled cat and dog images.
2. Preprocess and normalize image data.
3. Train a neural-network classifier.
4. Evaluate predictions on validation or test images.

## Getting started

Open the notebook in Jupyter Notebook or Google Colab, configure the dataset path used in the notebook, install the imported dependencies, and run the cells in order.

## Technologies

- Python
- TensorFlow / Keras
- Jupyter Notebook
